## HTTP (morning)

Current `POST /voice/clips` hears, extracts, **and books**. That skips Check the plan. Split:

| Call | In | Out | Writes book? |
|---|---|---|---|
| `POST /voice/hear` | multipart `audio` | `{ transcript }` | no |
| `POST /voice/extract` | `{ kind: "MORNING_PLAN", transcript }` | `{ title, commitments }` | no |
| `POST /days/morning` | `{ timezone, transcript, title, commitments }` | `DayRecord` | **yes** |

`POST /voice/clips` stays for **evening** (not this slice). Morning clips must not book.

`days.title` is `TEXT NULL`. Gemini suggests a short name (“Heavy gym Tuesday”). User can edit on Check the plan. Empty title is allowed.

Audio rules stay: ≤2 MiB, `audio/mp4` / `m4a` / `x-m4a`. Empty speech → 422. Bad extract → 502. Speech/model down → 503.

## Phone

Steps are local state on Talk. No new route.

1. **Record** — large forest mic, waves from `expo-audio` metering. No on-device captions (no extra native module).
2. **Your words** — after `POST /voice/hear`. Editable.
3. **Thinking** — `POST /voice/extract`. No fake commitments.
4. **Check the plan** — title + commitment lines. User can add, edit, delete.
5. **Save** — `POST /days/morning` → `router.replace('/today')`.

Type instead skips 1–2’s hear call.
