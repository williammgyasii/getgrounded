# Firebase

CLI: `firebase`

Firebase is the mobile platform, not the application database.

Use later:

- Authentication (email, Google, Apple)
- Analytics (no transcripts)
- Crashlytics
- Cloud Messaging
- App Check
- Remote Config

Do not add Firestore as the source of truth. Do not write GetGrounded business data from Expo into Firebase.

`firebase init` is not run yet. We will do that when we create the Firebase project.

Docs: https://firebase.google.com/docs/cli
