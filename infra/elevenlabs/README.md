# ElevenLabs

CLI: `elevenlabs`

```text
agents/    Talk to Coach and phone-agent config later
```

Two modes:

- **Quick Log** — Scribe / speech-to-text for morning and evening notes
- **Talk to Coach** — full agent only when conversation is worth the cost

ElevenLabs owns the conversation. The .NET API owns the data. Never treat an ElevenLabs agent as the canonical store.

Do not run `elevenlabs auth login` from this chat. You do that locally when you are ready.

Docs: https://elevenlabs.io/docs/eleven-agents/operate/cli
